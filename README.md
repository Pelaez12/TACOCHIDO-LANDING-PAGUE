# Taco Chido

Landing de enlaces basada en MANCHA-BURGER, con la identidad del manual de marca de Taco Chido.

## Vista local

```powershell
cd TACO-CHIDO
npm install
npm run dev
```

Abre http://127.0.0.1:8089/. Para compilar: `npm run build`.
